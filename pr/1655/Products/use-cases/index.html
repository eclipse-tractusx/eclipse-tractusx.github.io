What maturity and activity mean

Maturity says how far a product has come; the teams set it. Activity is worked out from GitHub every day: a product is active when a person committed to the main branch of one of its repositories in the last 6 months. Dependency updates by bots do not count.

Productive
Part of the Eclipse Tractus-X release, runs in productive dataspaces and has an active team of maintainers.
Mature
Released, maintained and ready to build on. Not yet proven in productive dataspaces, so expect changes between releases.
Incubating
Early stage. Try it and give feedback; interfaces can change and it is not meant for production yet.
Phase-out
Still available, but being replaced or reduced. Plan the move to its successor.
Active
A person committed to the main branch in the last six months.
Stale
No commit by a person on the main branch for more than six months. Dependency updates by bots do not count.
Deprecated
Proposed for archiving under TRG 7.09, or all repositories are archived. No more security fixes.
