How they work

Built for open-source collaboration

Grounded in the code

The agents answer from the code, configuration and specifications they open in the session, not from memory, and they cite the files they used.

Release Guidelines built in

The KIT Master Builder and the Umbrella Guardian review changes against the Tractus-X Release Guidelines and cite the TRG with a fix.

Open about being AI

When the agents with a picture write on GitHub, they post under their own avatar with an AI disclosure and name the person on whose behalf they act.

One crew

Each agent owns its product. The Dataspace Captain and the Identity Keeper hand questions about other products to the agent that owns them.

One crew

Agents that call each other

Ask the Dataspace Captain a question that belongs to another product, and it names the agent to ask and the exact question to ask it.

Dataspace Captain

Sees the whole chart: it answers the Dataspace Management part itself and calls the specialist that owns the product for everything deeper.

Get started

Talk to an agent in two minutes

Clone the repository of the product you work on. The agent comes with it.

Claude Code

Start Claude Code with the agent from the repository root. The agent id is the file name of its definition, for example connector-sensei or umbrella-guardian.

git clone https://github.com/eclipse-tractusx/tractusx-edc.git
cd tractusx-edc
claude --agent connector-sensei

GitHub Copilot

Open the repository in VS Code, open Copilot Chat in agent mode and select the agent in the agent picker. Reload the window if it does not appear yet.

  1. Open the repository in VS Code.
  2. Open Copilot Chat and switch to agent mode.
  3. Pick the agent, for example Connector Sensei, and ask your question.

Bring your repository's agent

Does your Tractus-X repository have an agent? Show it here, so the community can find it.

  1. Put the agent definition and its picture in .github/agents/ of your repository, with a REUSE.toml for the picture.
  2. Add the agent and its profile to data/aiAgents.js of this website and a 720×720 WebP of its picture to static/img/ai/agents/.
  3. Run npm run validate:ai and open a pull request.
